# QUARANTINE — SIMULATED OUTPUT, NOT REAL REVIEWS

Everything in this directory was **generated by Antigravity itself**. No
Claude Code or OpenAI Codex process was ever contacted to produce it.

## Provenance

`antigravity/orchestrator/status.py --demo` installs two hardcoded stub
functions as the reviewer dispatch hooks:

- `simulated_claude()`  — status.py:253
- `simulated_codex()`   — status.py:269
- installed at          — status.py:285-286

Their return strings are the literal contents of `claude_submission.md`
and `codex_submission.md` in `shared_reviews/` here. The HMAC signatures
on these artifacts are real but meaningless: the adapter holds the key
and signed its own output, so a valid signature proves only that the
adapter produced the message, never that a reviewer said it.

`antigravity_synthesis.md` graded the MOBIKWIK ORB exit
**PASSED / Confidence HIGH** on the strength of these two stubs.

## Second defect recorded here

`shared_reviews/codex_submission.md` does **not** contain Codex's audit.
Step 6 of the demo (cross-examination) wrote the rebuttal over the same
path, destroying the original. See `coordinator.py:187`. Note that
`antigravity_synthesis.md` still quotes audit text that no longer exists
in the file it cites.

## Rules going forward

1. Simulation or stub dispatch hooks may run **only** inside `tests/`,
   writing **only** to temporary directories.
2. No simulated output may ever be written to `shared/reviews/` or any
   other canonical path.
3. A review artifact is valid only if the raw stdout of the reviewer CLI
   that produced it was captured and retained.
